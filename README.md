# 🎃 JACK'S HOUSE — хэллоуин-хоррор для Roblox (v2)

Игра для 2-8 игроков: проклятый дом, двери, монстр, предатель среди своих и конфеты.

**v2 — визуальный апгрейд:** код теперь САМ строит атмосферные комнаты
(тёмное дерево, каменные стены, мерцающие свечи, светящиеся тыквы, дверные
рамы с колоннами), двери открываются с анимацией, премиальный HUD,
пульсирующее «ОН РЯДОМ», скример при смерти. Строить руками почти ничего не нужно.

---

## Что уже сделано (кодом)

- Раунды: лобби → отсчёт → дом → итоги, всё автоматом
- 12 комнат строятся автоматически из кода (или из твоего шаблона — опция)
- Атмосфера: мерцающие свечи, тыквы, туман, ночное освещение
- Двери открываются касанием с анимацией (уезжают в пол), прогресс виден в HUD
- Монстр: просыпается после 2-й двери, гонится за ближайшим, убивает касанием
  (если не хочешь искать модель — код соберёт встроенного монстра с красными глазами)
- Отключение света каждые ~40 сек — в темноте монстр быстрее
- ПРЕДАТЕЛЬ: при 3+ игроках один случайный получает кнопку «СТУК» —
  монстр 10 секунд гонится за случайной жертвой. Кто предатель — никто не знает
- HUD: панель фазы с полосой прогресса, конфеты, отсчёт, виньетка по краям
- «⚠ ОН РЯДОМ ⚠» — пульсирующее предупреждение, когда монстр ближе 50 стадов
- Скример-оверлей «💀 ТЫ МЕРТВ» при смерти
- Конфеты: за двери (+5), за побег (+25), предателю за жертву (+15)
- Конфеты сохраняются между заходами (DataStore)
- Фонарик: кнопка 🔦 или клавиша F

## Шаг 1. Установка и новый проект

1. Открой https://www.roblox.com/create → войди → Start Creating (установится Studio)
2. New → **Baseplate**
3. Вкладка **View** → включи **Explorer** и **Properties**

## Шаг 2. Лобби

1. Поставь **SpawnLocation** в стороне от начала дома, например на X = 200
2. Сделай площадку-лобби (пол, стены, приветственная табличка — по желанию)
3. Добавь НЕВИДИМУЮ часть в лобби:
   - Name = `LobbySpawn`
   - Anchored = ON, CanCollide = OFF, Transparency = 1
   - Положи на пол лобби — туда игроки возвращаются после раунда

⚠️ Лобби должно быть ДАЛЕКО от коридора дома (минимум 300 стадов по оси X),
иначе монстр будет видеть игроков в лобби.

⚠️ Дом строится кодом от точки (0, 0, 0) в сторону −Z (стандартный базовая плита).
Не ставь лобби в минус по Z.

## Шаг 3. (ОПЦИОНАЛЬНО) Своя комната и монстр

- **Комнаты строятся сами.** Хочешь свою уникальную комнату — создай в
  ServerStorage папку `GameAssets`, внутри Model `RoomTemplate`
  (пол/стены/декор + Part `Door` на дальней стене + невидимый Part `SpawnPad`
  у входа), и поставь в GameConfig `AUTO_BUILD_MAP = false`
- **Монстр тоже встроен** (тёмная фигура с горящими красными глазами).
  Хочешь модель покруче — возьми в Toolbox любую модель монстра, назови
  модель `Monster`, положи в ServerStorage/GameAssets и заякори все её части

## Шаг 4. Скрипты

| Файл из репозитория | Куда в Studio | Тип |
|---|---|---|
| `ServerScriptService/Halloween/Main.server.lua` | ServerScriptService → папка **Halloween** → объект **Main** | Script |
| `.../Modules/GameConfig.lua` | Halloween → **Modules** → `GameConfig` | ModuleScript |
| `.../Modules/CandyManager.lua` | Modules → `CandyManager` | ModuleScript |
| `.../Modules/MapGen.lua` | Modules → `MapGen` | ModuleScript |
| `.../Modules/MonsterAI.lua` | Modules → `MonsterAI` | ModuleScript |
| `.../Modules/RoundManager.lua` | Modules → `RoundManager` | ModuleScript |
| `StarterPlayerScripts/GameClient.client.lua` | StarterPlayer → StarterPlayerScripts → `GameClient` | LocalScript |

Как вставлять: правый клик на папке в Explorer → Insert Object → нужный тип,
назови ТОЧНО как в таблице, удали строку `print("Hello world!")` и вставь код.
В каждый файл — только содержимое файла, без строк пути.

Структура в Explorer:

```
ServerScriptService
└─ Halloween (Folder)
   ├─ Main (Script)
   └─ Modules (Folder)
      ├─ GameConfig (ModuleScript)
      ├─ CandyManager (ModuleScript)
      ├─ MapGen (ModuleScript)
      ├─ MonsterAI (ModuleScript)
      └─ RoundManager (ModuleScript)
StarterPlayer
└─ StarterPlayerScripts
   └─ GameClient (LocalScript)
Workspace
├─ LobbySpawn (Part)
└─ SpawnLocation (лобби)
(дом построит код сам при запуске)
```

## Шаг 5. Включи сохранения (DataStore)

1. Home → **Game Settings** → Security
2. Включи **Enable Studio Access to API Services** → Save
3. File → **Publish to Roblox** (нужно для работы DataStore)

## Шаг 6. Тест

1. В `GameConfig` поставь `MIN_PLAYERS = 1`
2. Нажми **Play**: дом построится сам, через 20 сек раунд начнётся
3. Мультиплеер-тест: вкладка **Test** → Clients and Servers → 3 Players → Start
4. Смотри вкладку **Output** (View → Output): если там красные ошибки —
   скопируй текст и пришли, починим

## Шаг 7. После теста

- Верни `MIN_PLAYERS = 2`
- Крути баланс в GameConfig: скорость монстра, частота блэкаута, длина дома
- Публикация: File → Publish, потом на сайте roblox.com в настройках игры включи Public

## Баланс (подкрути в GameConfig)

- Монстр медленнее игрока (13 против 16) — убежать МОЖНО,
  но в темноте (20) — почти нет
- «ОН РЯДОМ» загорается за 50 стадов — время среагировать есть
- Предателю выгодно, чтобы гибли другие (+15 за жертву),
  но сам он тоже бегает от монстра
